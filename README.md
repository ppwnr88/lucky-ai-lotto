# Lucky AI Lotto

เว็บคำนวณเลขนำโชคจากข้อความ/ความฝันด้วย AI  
ใช้ Next.js + TypeScript + OpenRouter

## Features

- วิเคราะห์ข้อความด้วย AI
- สร้างเลข 2 ตัว / 3 ตัว
- Caption กวน ๆ
- หน้า SEO ทำนายฝัน 1,000+ หน้า
- Sitemap + Robots
- Google AdSense ready
- Share result เป็นรูปภาพ

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- OpenRouter API
- Vercel
